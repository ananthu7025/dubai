# Khattourism LLC

A premium, modern travel portal specializing in customized luxury sightseeing packages and experiences in Dubai and Abu Dhabi. Built with native responsive components, custom hand-drawn SVG background tapestries, and smooth scroll animations.

## Key Features

- **Floating Glassmorphic Header**: Interactive navigation capsule with frosted glass filters.
- **Panel Grid Itineraries**: Border-linked grid layout displaying sightseeing highlights alongside sharp 1:1 square pictures.
- **Vector SVG Doodles Backdrop**: Light-mode outline drawings of Dubai's key landmarks (Burj Khalifa, Burj Al Arab, Mosque, desert camel guide, palm trees, sun, and ocean waves) layered directly behind grid cells.
- **Signature Perks**: Formatted 4-column panel grid showcasing exclusive amenities.
- **Visual Diary**: Responsive staggered masonry-style collage grid representing travelers' real captured moments.
- **FAQ Accordion**: Interactive Q&A list with smooth CSS collapsible transitions.
- **Dynamic Animations**: Smooth Lenis scrolling and staggered GSAP entrance effects.

## Technologies Used

- **HTML5 & CSS3** (Vanilla Grid, Flexbox, Variable Tokens, SVG)
- **Javascript** (GSAP ScrollTrigger, Lenis Smooth Scroll, Swiper Carousel)
- **Icons**: Boxicons Pack
